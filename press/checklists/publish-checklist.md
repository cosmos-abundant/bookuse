# 출간 준비 체크리스트

`/publish-prep`에서 편집장이 전 항목 확인. 미충족 항목이 있으면 출간 준비 미완료.

## 원고

- [ ] 전 챕터 퇴고 게이트 통과 (STATUS.md 확인)
- [ ] 본문에 `[확인필요]` 표시 0건 (검색으로 확인)
- [ ] 전체 감수(full-factcheck) 오류 0건
- [ ] 용어집(`glossary.md`) 기준 전 챕터 용어 통일
- [ ] 챕터 간 중복·충돌 최종 확인 (dev-editor 전체 통독 보고서)
- [ ] 분량이 기획안 사양 ±20% 이내 (벗어나면 사유 기록)

## 책의 앞뒤 (front/back matter)

- [ ] 머리말 (이 책의 약속, 읽는 법, 시점 일러두기 — AI활용법 필수)
- [ ] 목차 최종본 (본문 제목과 일치)
- [ ] 참고 문헌 / 출처 목록 (자료카드에서 생성)
- [ ] 찾아보기 후보 키워드 목록 (논픽션)

## 도판

- [ ] 모든 도판에 삽입 위치·캡션·대체 텍스트 존재
- [ ] 본문 수치와 도판 수치 일치
- [ ] 외부 생성 필요 일러스트의 브리프 완성

## 마케팅

- [ ] 마케팅 킷 완성, 모든 카피에 근거 챕터 주석
- [ ] 제목 최종안에 대한 red-team-reader 의견 청취

## 권리·윤리

- [ ] 인용문 전수: 출처 표기 확인, 인용 분량이 공정 이용 범위인지 검토
- [ ] 타인 저작물(이미지, 표, 긴 인용) 사용 허락 필요 목록 작성
- [ ] 실존 인물·기업 언급 부분의 법적 리스크 검토 (사실 적시 근거 확인)
