# AI 활용법 스타일가이드

common.md + practical.md(실용서 규칙 전부 적용)에 더해 적용. AI 분야는 책이 나오는 순간부터 낡기 시작한다 — 그 운명을 설계에 반영한다.

## 휘발성 관리 (이 장르의 생명선)

- **시점·버전 명시 의무.** 도구 화면, 기능, 가격, 모델명을 언급하는 모든 절은 "2026년 N월, 버전 X 기준"을 명시한다. 책 머리에 일러두기로 총괄 명시 + 변동 가능성 높은 곳은 본문에도.
- **원리와 절차를 분리해서 쓴다.** 각 챕터에서 "이 도구가 바뀌어도 유효한 것"(원리, 판단 기준, 사고방식)과 "지금 시점의 구체 절차"를 구분한다. 원리가 본문의 뼈대, 절차는 그 적용 사례로 배치한다. 절차만 있는 챕터는 책이 아니라 매뉴얼이다.
- UI 단계 의존 최소화: "왼쪽 위 파란 버튼" (X) → "새 대화를 시작하고" (O). 버튼 위치는 바뀌어도 동작 개념은 남는다.

## 재현성

- **모든 프롬프트 예시는 전문을 싣는다.** "이런 식으로 요청하면" 금지. 입력 전문 → 실제 출력(요약 가능, 단 요약임을 표시) → 결과 평가.
- 예시는 실제로 실행해본 것만 싣는다. 실행 못 한 예시는 [확인필요] 처리.
- **잘 안 되는 경우를 반드시 다룬다:** 환각, 맥락 누락, 같은 프롬프트의 출력 변동. AI의 실패 패턴을 다루지 않는 AI 책이 바로 슬롭이다.

## 윤리·정확성

- 능력 과장 금지: "AI가 다 해줍니다" (X). 사람이 해야 할 검증·판단을 항상 명시.
- 모델·도구 비교는 자료카드 근거 + 확인 시점 명시. 카더라 벤치마크 인용 금지.
- 저작권, 개인정보, 회사 기밀 입력 등 실무 리스크를 해당 활용법과 같은 자리에서 다룬다 (부록으로 미루지 않기).
