## 항목별 해소 확인

### ① P1① — 7가지 약속과 본문 번호 봉합 (해소)

작가가 1회차 권장안 (A)를 채택해, 무음 실패를 본문 전체에서 "패턴 7"로 번호 매겼다. 추적 결과 번호 체계가 끊김 없이 봉합됐다:

- 제목(1행) "7가지 패턴" 유지 → 도입(7행) "일곱 가지… 여섯은 안 온다, 일곱째는 왔는데 틀렸다. 6+1로 갈리는 이 구분… 마지막 일곱째를 패턴 7로"로 7=6+1을 도입에서 못 박음.
- 2절(13행) "일곱은 여섯과 하나로 갈린다 — 패턴 1부터 6까지… 패턴 7"로 번호 체계를 독자에게 미리 줌(1회차 마지막 주문 충족).
- 6절 제목(119행)이 옛 "가장 위험한 패턴"에서 **"패턴 7 — 무음 실패(왔는데 틀린 보고서)"**로 교체됨. grep 확인 결과 "가장 위험한 패턴"·"일곱째 패턴"·"나머지 하나" 잔존 0건.
- 그림 10-1 캡션(21행)도 "패턴 1~6… 패턴 7 무음 실패"로 일치.
- **"패턴 7 실종" 사라짐 확인.** 독자가 "패턴 7은 어디 있지?"를 추론할 필요가 없다 — 도입·2절·6절 제목에서 세 번 명시된다.
- **두 방어선 골격 유지 확인.** 19행("앞은 패턴 1~6+진단 순서, 뒤는 패턴 7+마지막 그물")·121행("첫 번째 방어선/두 번째 방어선")이 그대로 살아 번호 통일이 골격을 해치지 않았다. 오히려 "패턴 1~6 = 1방어선 / 패턴 7 = 2방어선"으로 번호와 방어선이 일대일 대응돼 골격이 더 또렷해졌다.

### ② P1② — 체크리스트 기입란과 [확인필요] 구분 (해소)

- 149·151행의 대괄호 작업 메모가 **밑줄 빈칸 양식**("(내 도구의 연결 관리 화면 위치 → ______________ 여기에 적어 둔다)")으로 교체됨. 시각적으로 "독자가 직접 써 넣는 칸"임이 분명해졌고, 책의 `[확인필요: …]` 관례와 표기상 충돌하지 않는다.
- 154행도 "빈칸 두 곳 — 연결 관리 화면과 실행 기록 화면의 위치 — 만 당신 도구에서 실제로 찾아 적어 두면 된다"로 호응.
- 표 10-2 캡션(156행)에 1회차 주문대로 **"독자가 자기 도구의 화면 위치를 직접 적어 넣는 기입란(작가 미완 표시가 아님 — 조판 시 밑줄 빈칸 양식으로 확정할 것)"**을 조판/일러스트레이터에게 명시. grep 확인 결과 본문 내 `[확인필요` 잔존 0건.

### ③ P2 — 무음 중복 병합 / 표 캡션-본문 매핑 (해소)

- **무음 5·6절 병합 매끄러움(해소).** 옛 5절(무음 위험성 선언)이 6절로 흡수돼, 현 6절(119~133행)이 "위험성 선언(121) → 왜 위험한가(123·125) → 두 입구=패턴 5·6(127) → 진단 안 통함(129) → 사람도 못 잡음=자동화 편향(131) → 검수가 답(133)"의 한 흐름으로 정렬됐다. 1회차의 기시감(같은 논증을 두 절에서 소진)이 사라졌다. "통째/일부 빔" 구분도 진단 순서(93행)와 무음 입구(127행) 두 곳으로 정리돼 1회차 지적한 3중 반복이 해소됐다(71행 패턴 5 자리 고유 정보는 유지 — 의도대로).
- **표 10-1 캡션-본문 매핑 일치(해소).** 1회차에 빠져 있던 패턴 3을 4단계 본문(99행)에 추가: "빨간불이 AI 호출 단계에 켜져 있고 그 옆에 모델 이름과 함께 오류가 떠 있으면 패턴 3(모델 은퇴)이다 — … 살아 있는 모델로 갈아끼운다." 표 10-1 캡션(101행)의 "모델 호출 실패는 패턴 3"과 본문이 일치. 6패턴 전부가 진단 4단계에 매핑됨(출력 자리→방향, 연결=1·2, 소스=5·6, 실행 기록=4의 429·3의 모델 오류).
