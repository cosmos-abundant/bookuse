## 1. [확인필요] 5건 — 항목별 판정 + 마커 처리 권고

### ⓐ 네이버 키 발급 권한 수준 (53절) — **불확실 → 공개 출처로 상당 부분 해소 가능 (U-1)**

- 본문: "단정하긴 어렵지만, 키 발급에는 계정 권한이 필요할 수 있다. … 운영하는 권한이 아니거나, 대행사가 운영하는 계정에 권한만 받아 들어가 있다면 메뉴가 안 보이거나 신청이 막힐 수 있다."
- 카드 대조: 카드 16 반대근거 + ch05-build 미확인 목록 = "권한 이슈 있을 수 있음, 정확한 요건 V-2 실측" — 카드는 여기까지만 닫았다. 본문 서술은 카드 한도 내(추정 수위 유지)라 **카드 초과는 아니다.**
- 공개 출처 추가 확인 결과: 네이버 검색광고 API 개편 안내(아이디어키 공지 요약) — **"운영관리 권한을 가지고 있을 경우 API 라이선스 및 키값 발급이 불가하고 API 연동을 진행할 수 없다."** 즉 *운영관리 권한만으로는 발급 불가, 계정 책임자(마스터) 권한이 필요*하다는 방향이 공개 출처로 확인된다. 공식 저장소 Issue #1296도 "계정 책임자만 확인 가능한지" 묻는 동일 맥락(단 네이버 공식 답변은 미확정).
- **판정: 불확실(출처 방향은 일치하나 "정확한 권한 등급명"은 공식 1차 미확정).** 본문의 "권한이 필요할 수 있다"는 틀리지 않았고, 오히려 공개 출처는 더 단정해도 되는 쪽이다.
- **정정/마커 처리 권고:**
  1. [확인필요] 마커는 **삭제 가능.** 단 본문 수위를 한 단계 구체화 권장: "키 발급에는 계정 권한이 필요할 수 있다" → "키 발급에는 광고 계정의 책임자(마스터) 수준 권한이 필요하고, 운영관리 권한만으로는 발급 메뉴가 막힐 수 있다(2026년 6월 기준)."
  2. 정확한 권한 등급명은 V-2 발행인 실측으로 한 번 더 맞추되, 못 맞추면 현 "~필요할 수 있다" 수위 유지로도 출간 가능(카드 한도 내).

### ⓑ 아임리포트 가격·무료 기간 라이브 재확인 (67절) — **발행인 실측 확정 대기 (U-2)**

- 본문: "아임리포트는 2026년 6월 기준 월 9,900원이고, 14일 무료로 써 볼 수 있다. … [확인필요: 아임리포트 가격·무료 기간 — 출간 직전 라이브 페이지에서 재확인.]"
- 이 수치는 V-1 발행인 1차 실측 → 사실 검증 대상 아님(지시대로).
- **다만 라이브 교차에서 상충 신호 1건 포착(보고 의무):** 공개 검색 요약에 아임리포트가 **"베타 기간 동안 서비스 무료 제공"**이라는 문구가 보인다(imreport.io / 유튜브 소개). 발행인 실측치(월 9,900원·14일 무료)와 표면상 어긋날 수 있다 — 베타 종료 후 유료 전환, 또는 플랜별 차이일 가능성. imreport.io·마켓플레이스 상세는 403으로 원문 직접 열람 불가.
- **판정: 발행인 실측 확정 대기.** 에이전트가 닫을 수 없는 항목(가격은 V-1 발행인 권한). 단 상충 신호가 있어 **출간 직전 라이브 재확인이 형식이 아니라 실질로 필요**하다.
- **마커 처리 권고:** [확인필요] 마커를 그대로 출간본까지 끌고 가지 말 것. 출간 직전 발행인이 라이브 페이지 1회 확인 후 → 마커를 삭제하고 본문에 "(2026년 6월 ○○일 라이브 확인)" 형태의 확정 일자만 남긴다. **베타 무료 여부를 반드시 함께 확인**(현재 무료라면 "월 9,900원" 서술이 시점상 틀릴 수 있음).

### ⓒ 네이버 수동 다운로드 형식·경로·소요 (75절) — **확인 (형식·경로) / 발행인 실측 대기 (소요 시간)**

- 본문: "보고서 메뉴에는 … 엑셀 형식으로 뽑는 맞춤 보고서 기능이 있다. 매주 쓸 보고서를 한 번 만들어 저장 … 기간만 지난주로 바꿔 다운로드 … [확인필요: 정확한 형식과 열 구조, 클릭 경로, 수동 단계 소요 시간 — 발행인 실측 확인.]"
- 카드 대조: 카드 10 — 다차원 보고서를 엑셀 피벗테이블 형식으로 만들고 **저장(템플릿 재사용) 가능**. 일치.
- 공개 출처 추가 확인(마케팅 인사이드 등): "다차원 보고서에서 맞춤 보고서를 **엑셀** 파일로 다운로드, **보고서 형식 저장** 가능. **기간을 선택 후 다운로드.** 보고서 형식 저장은 다운로드 파일 저장이 아니므로 매번 다운로드 필요." → 본문 절차("저장해 두고 기간만 바꿔 다운로드")와 **정확히 일치.**
- **판정: 형식(엑셀)·저장·기간변경 다운로드 경로는 확인.** 정확한 열 구조와 "약 5분" 소요는 발행인 실측(V-6) 영역.
- **마커 처리 권고:** [확인필요] 마커 **삭제 가능.** 형식·경로는 공개 출처로 닫혔다. 단 "약 5분"(77절)은 V-6 실측치이므로, 마커를 지우되 소요 시간은 발행인 실측 수치임을 전제로 둔다(본문이 이미 "약 5분"으로 완화 표기 — 적정). 정확한 파일 확장자(xlsx)를 본문에 박을지는 V-6에서 확정.

### ⓓ 메타 비즈니스 권한 난도 (91절) — **발행인 실측 확정 대기 (절차는 공개 출처로 확인)**

- 본문: "막히는 자리는 … 계정 권한이다. … 비즈니스 계정 관리자에게 자기 계정을 광고 계정에 추가해 달라고 요청 … [확인필요: 메타 비즈니스 계정 권한 부여의 실제 난도와 앱 검수 요구 여부 — 발행인 실측 확인.]"
- 카드 대조: 카드 18 반대근거 — "비즈니스 설정 > 사용자 > 사람에서 최소 Employee 권한 추가 + 광고 계정 권한 부여" 필요. 일치.
- 공개 출처 추가 확인(메타 비즈니스 지원센터 요약): "비즈니스 설정 > 사용자 > 사람 > 추가 > 이메일 입력 > 자산(광고계정) 권한 부여" 절차 확인. 권한 없으면 초대 버튼 비활성. **절차 자체는 본문 서술과 일치.**
- **앱 검수(App Review) 요구 여부:** 본문이 묻는 "앱 검수 요구 여부"는 사용하는 커넥터가 어떤 권한 스코프를 쓰는지에 달려 있어 공개 출처로 일률 확정 불가. 일반 보고용 커넥터(Make Facebook Insights 등)는 통상 사용자 OAuth로 처리되나, 페르소나 체감 난도와 검수 발생 여부는 V-4 발행인 실측 영역.
- **판정: 권한 부여 절차는 확인 / 난도·앱 검수 여부는 발행인 실측 대기.**
- **마커 처리 권고:** [확인필요] 마커를 출간본까지 끌지 말 것. V-4 실측 후 → 마커 삭제. 실측에서 앱 검수가 발생하지 않았다면 본문에서 "앱 검수" 언급을 빼고 "계정 권한 추가 한 번"으로 단순화 가능. 실측 전이라면 본문을 "막히는 자리는 키나 서명이 아니라 계정 권한이다"까지만 단정하고 검수 관련 단정은 넣지 않는 현 수위 유지(안전).

### ⓔ 구글 공식 부가기능 지역 제한 (101절) — **확인 (해소)**

- 본문: "구글 공식 부가기능은 … 2026년 6월 기준 영어 버전 구글 시트·미국에서만 제공돼 … '이 앱은 당신의 국가에서 사용할 수 없습니다'가 뜬다. … 한국 독자의 기본 경로는 … 메타와 똑같은 로그인형 커넥터다. [확인필요: 구글 공식 시트 부가기능의 한국 지역 제한 현황 — 출간 직전 재확인.]"

## 2. 교정자 회부 — 채널 지표명 (메타 '구매' / 네이버 '전환')

- **메타 '구매(purchase)':** 공개 출처 확인 — 메타 광고의 전환 결과 지표 정식 명칭은 **"구매(Purchase)"**가 맞다. 본문 표기 정확.
- **네이버 '전환':** 네이버 검색광고의 정식 지표명은 **"전환수"**다(전환 기여기간·집계 정책 별도). 본문은 위치마다 표기가 흔들린다:
  - 3절·25절(저자 1인칭)·107절: "네이버의 '전환'" / "메타의 '구매 전환'" / "네이버의 '전환수'" — 혼용.
  - 25절: "메타의 '구매 전환'과 네이버의 '전환수'" / 동일 절 뒤에 "메타의 '구매'와 네이버의 '전환수'".
  - 109절: "메타의 '구매'와 네이버의 '전환수'".
- **판정: 오류 아님(개념·서술은 정확) / 표기 일관성 결함 — 교정자 회부.**
- **정정안:** 정식 지표명으로 통일 권장 — 메타는 **'구매'**, 네이버는 **'전환수'**로 책 전체 고정. 특히 3절의 "메타의 '구매'와 네이버의 '전환'" → "메타의 '구매'와 네이버의 '전환수'"로 맞출 것(네이버 정식명은 '전환'이 아니라 '전환수'). "구매 전환"(25절)은 메타 UI 정식 라벨이 '구매'이므로 '구매'로 통일하거나, 설명적 표현임을 의도했다면 작은따옴표를 빼서 지표명과 구분.
- **추가 주의(개념 정확성 보강, 선택):** 두 지표는 전환 기여기간이 달라(네이버 클릭 후 15일 vs 메타 7일클릭+1일 등) 같은 칸에 합치면 동일 기준이 아니다. 본문 25절은 "한 칸에 합칠지 따로 둘지"를 독자 판단으로 열어 두어 이 함정을 이미 피하고 있다 — 정확. 추가 정정 불요.

## 4. 시트 허브 · CSV 구분자 원리 (카드 20)

- 본문 27절: CSV = 한 구분자(쉼표·세미콜론·탭)로 값을 끊어 칸으로, 줄바꿈으로 행으로 / 표준 없음, 양쪽 약속만 지키면 됨 / 숫자에 쉼표 섞이면 세미콜론 사용. `여름세일,메타,3.2,2.8` 예시 = 쉼표 3개 → 네 칸.
- 카드 20과 대조: 핵심 문장 4개("구분 문자 한 글자로 필드 구별 / 필드·레코드 구분자 / 표준 없음, 약속만 지키면 됨 / 숫자에 쉼표면 세미콜론") **전부 일치.** 예시도 정확(쉼표 3개 = 4필드).
- 29절: "독자는 구분자를 직접 다루지 않는다, 노코드 도구가 처리" — 카드 20의 페르소나 가드레일("직접 파싱 안 시킨다") 준수. 저자 경험 원형(AI API가 구분자로 뱉게 하는 개발 방식)을 본문에 넣지 않음 — 카드 지시 준수.
- 시트 허브 논거(13~19절): 카드 11과 일치. "모든 커넥터가 시트를 지원한다"는 전칭 명제를 피하고 "약속이라도 한 듯 모두 구글 시트를 기본 도착지로"(17절)로 관찰 수위 유지 — 카드 11 메모("전칭 명제로 쓰지 말 것") 준수. 한계(수만 행→시트 한계, 다른 책 영역) 명시(19절) — 카드 11 반대근거 반영. **확인.**

## 게이트 판정 및 처리 지침

- **현재: 미통과** (본문에 [확인필요] 마커 5개 잔존, 오류는 0건).
- **통과 조건:**
  1. ⓐ ⓒ ⓔ — 공개 출처로 해소됨. **마커 삭제** (ⓐ는 권한 수위 구체화 권장, ⓒ는 형식·경로 확인됨).
  2. ⓑ ⓓ — 발행인 실측 확정 대기. **마커를 출간본까지 끌지 않는다.** 출간 직전 발행인이 V-1(가격, 베타무료 여부 포함)·V-4(메타 권한 난도·앱검수) 실측 1회 → 마커 삭제 + 확정 문구/일자 기입. 못 닫으면 red-team/발행인 판단으로 올림.
- 오류 0건이므로 작가 수정 루프는 경량(마커 제거 + ⓐ 수위 구체화 + 지표명 통일)으로 충분. 지표명 통일은 교정자 회부 건이다.
