### 1-2. Royal Society 과잉일반화 "약 5배" (line 59) — 확인

### 1-3. Pew 링크 부패 "38%" (line 75) — 확인

## 3. 수집 합법성 (4건 — 전부 확인, 수위 우수)

### 3-1. 한국 대법원 2021도1533 형사 무죄 (line 87) — 확인
- 본문: "한국 대법원은 공개 데이터 크롤링을 형사상 무죄로 본 적이 있다(2022년, 사건번호 2021도1533). 그러나 형사 무죄가 민사 면책은 아니다."
- 카드 09 + 외부 교차(대법원 2022. 5. 12. 선고 2021도1533, 크롤링 형사 최초 판결, 정보통신망침입·DB무단복제·업무방해 전부 무죄) 일치.
- **사건번호 단정 위험성 검토: 안전.** 사건번호 자체는 1차 판결로 확정된 사실이라 인용해도 무방. 위험은 "무죄 = 합법"으로 읽히는 것인데, 본문이 "형사 무죄가 민사 면책은 아니다"로 즉시 차단 → 카드 09 반대근거(중대 오류 경고)를 정확히 지킴.
- 본문 연도 표기 "2022년"은 선고일(2022-05-12) 기준으로 정확.

### 3-2. "형사 무죄 ≠ 민사 면책" 수위 (line 87) — 확인
- 본문: 부정경쟁행위·DB제작자 권리 침해로 다툰 사례가 별도로 있고, 무임승차로 사업에 쓰면 특히 그렇다고 서술. 카드 09(사람인/잡코리아 맥락) 일치.
- **수위 우수.** 사람인 사건의 **사건번호·심급을 인용하지 않음**(카드 미확인 목록: 사건번호 미확정) → 미확정 항목을 단정하지 않는 무결성 원칙 준수. "다투어진 사례가 별도로 있고"로만 처리.

### 3-3. robots.txt (line 87) — 확인

- **수위 적절.** 본문은 Ziff Davis 사건명/DMCA 세부를 11장으로 위임하고 원리만 한 줄 인용 → 카드 08 "강하게 일반화 금지" 준수.

## 4. 무결성 — 가짜 출력 / [확인필요] 슬롯 (6건 점검 — 위반 0)

### 4-1. 형식 예시(line 107) = 가상 라벨 확인 — 위반 없음
- line 107의 "어제 새로 올라온 프로모션이 있으면 가격·기간·대상 조건을 칸으로 적고..."는 **독자가 작성하는 요약 명세(프롬프트)**이지, AI가 뱉은 출력이 아니다. 가짜 경쟁사명·가짜 가격·가짜 날짜가 전혀 없다. "(이건 형식 예시다 — 당신의 업무에 맞게 고쳐 쓴다.)" 명시 라벨까지 부착. **무결성 통과.**

### 4-2. "측정/실측" 표기가 진짜 데이터 아닌 곳에 없는지 — 위반 없음
- 본문 전체에서 "실측"은 **line 43의 [확인필요: 발행인 실측...] 한 곳**에서만 등장. 그 외 "측정/실측"으로 표기된 데이터 주장 없음. 경쟁사 가격 예시("30% 할인", "전 품목 세일" 등)는 모두 **검수 원칙을 설명하는 가정형 예시**로, 실제 측정값으로 위장하지 않음(line 65, 77 — "라 적었으면", "공지했는데 ... 적는다" 가정형). **위반 없음.**

### 4-3. 도입부 시간 수치(1시간 30분/1시간 10분/20분, line 3) — 무결성 OK
- 페르소나(김지유) 서사의 설정값으로, 실측 통계로 제시되지 않음. 문학적 설정 장치 — 사실 주장 아님. 문제 없음.

### 4-4. line 61 "마이너스 24%" — 4장 회수 참조
- 본문이 "(4장 도입의 그 마이너스 24%)"로 4장 출처를 명시 회수. ch04-factcheck에서 검증된 수치의 상호참조 — ch07 신규 검증 대상 아님. (ch04 팩트체크 통과 전제로 정합.)

### 4-5. [확인필요] 1건 (line 43, 경로 ⓒ) — 처리 권고
- 내용: "[확인필요: 발행인 실측 — 예약과 웹 리서치가 결합된 도구의 2026년 6월 시점 플랜·한도·결합 범위를 공식 도움말에서 확정. 미확정 상태에서 특정 제품을 '이렇게 하면 된다'로 단정해 쓰지 말 것.]"
- 대응 카드: 미확인 목록 "Claude Cowork 예약 작업 정확 플랜·한도·결합 범위" — researcher가 공식 도움말 403으로 1차 확정 실패한 항목.
- **감수자 판정: 이 [확인필요]는 감수자가 닫을 수 없다.** 이유: (1) 닫으려면 특정 제품의 현시점 플랜·한도·결합 범위를 공식 1차로 확정해야 하는데 공식 페이지가 403이고, (2) 본문 자체가 이 항목을 "동급 선택지로 권하지 않는다"며 **단정을 회피하는 방향으로 설계**되어 있어, 굳이 확정값을 넣지 않아도 본문의 사실 주장이 성립한다.
