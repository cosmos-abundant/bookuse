# 챕터 브리프: ch11 (회사에서 잘리지 않는 자동화 — 보안·개인정보·책임)

⚠️ **집필 순서 주의:** 3부지만 2부(ch05~09)보다 먼저 집필. 2부에서 짓는 시스템(광고 데이터 취합, 모니터링, 콘텐츠 변환)을 원리 수준으로 참조하고 특정 도구 절차에 의존하지 마라. 2부 완성 후 편집장 정합성 패스.

⚠️ **ch02 인계(각도 전환):** 책임 법리(Air Canada 판례, 한국 AI기본법)는 ch02 "자동화하면 안 되는 일"에서 이미 소개됐다. ch11은 그 법리를 **재설명하지 말고**, "그래서 내 회사에서 실무로 어떻게 선을 긋나"로 각도를 바꾼다. ch02 = 자동화 대상에서 뺄지 판단 / ch11 = 자동화하기로 한 일에서 데이터·책임 선 긋기.

- **독자가 얻는 것 (한 줄):** 고객 데이터·회사 기밀을 어디까지 AI에 넣어도 되는지 자기 회사 기준으로 판단하고, 자동화 산출물의 책임을 관리한다.
- **이 챕터가 답하는 질문:** "이거 회사 데이터를 외부 AI에 넣는 건데… 넣어도 되나? 사고 나면 내가 책임지나? 어디까지가 안전선인가?"
- **다뤄야 할 핵심 내용:**
  1. **도입:** 김지유가 자동화를 다 짜놓고 마지막에 멈칫하는 장면 — "이 광고 데이터에 고객 정보가 섞여 있는데, 매주 외부 AI로 자동 전송해도 되나?" 보안은 자동화의 마지막 관문이지 별책 부록이 아니다.
  2. **입력 전 비식별화 — 무엇을 넣고 무엇을 빼나:** AI에 넣기 전 거르는 기준. 개인정보(고객명·연락처·주민번호 등), 회사 기밀(미공개 실적·계약·내부 전략). 마케터 데이터에서 실제로 문제되는 항목 + 비식별화 방법(가명화, 집계값만, 샘플 제거). 체크리스트.
  3. **업무용 계정의 데이터 정책 읽는 법(2026년 6월 기준, [휘발성] 철저):** 같은 도구라도 무료/개인 플랜과 업무용/팀/엔터프라이즈 플랜의 데이터 학습 정책이 다르다. "내 입력이 모델 학습에 쓰이나"를 약관에서 확인하는 법. 개인 계정으로 회사 데이터 넣는 것의 위험.
  4. **책임 소재(ch02 각도 전환):** "AI가 만든 보고서"가 틀리거나 유출되면 책임은 회사·담당자에게 남는다(ch02 Air Canada 한 줄 참조만). 자동화일수록 "사람이 승인한 지점"을 남기는 법 — 로그, 검수 서명(4장 연결).
  5. **자기 회사 기준 만들기:** 회사에 AI 사용 규정이 있으면 따르고, 없으면 스스로 안전선을 긋는 법. 법무·보안팀에 물어야 할 질문. "허락받고 쓰기"의 실무.
- **다루지 않는 것:** 자동화 대상 선정(2장), 산출물 사실 검증(4장 — 책임 맥락에서 검수 서명만 연결), 도구 장애(10장), 도구 단종(12장). ch02 책임 법리 재설명 금지.
- **자료카드:** `research/ch11-security.md` (과업 E)
  - **각 AI·자동화 서비스의 데이터 처리 약관(2026년 6월 기준):** ChatGPT/Claude/Gemini의 개인·무료 vs 업무·팀·엔터프라이즈 플랜에서 입력 데이터의 학습 사용 여부·옵트아웃·보존 기간. 노코드 도구(Make/Zapier/n8n)의 데이터 처리 정책. 공식 약관·문서 원문 우선([휘발성], 확인일 필수).
  - 한국 개인정보보호법의 마케터 관련 핵심(개인정보 처리·제3자 제공·국외 이전 — AI 서비스가 해외면 국외 이전 이슈). 1차(법령·개인정보위 가이드).
  - 기업의 AI 데이터 유출 실명 사례(직원이 회사 기밀을 외부 AI에 입력해 문제된 사례 — 삼성 등 보도된 것, 출처·날짜 필수).
  - 비식별화·가명처리 실무 기준 근거.
  - 반대 근거: "업무용 플랜은 학습 안 하니 안전하다"는 주장의 한계(보존·해킹·하위처리자 등).
- **예상 분량:** 9,000자 (±20%)
- **앞뒤 챕터 연결:** ch02(자동화 제외 판단)·ch04(검수=책임 지점)에서 받음. ch12로 넘김(도구 갈아탈 때 데이터 이전·삭제). 2부 시스템이 "외부로 데이터를 보낸다"는 점을 원리로 전제.
- **스타일 유의:** ai-howto([휘발성] 철저 — 약관은 잘 바뀐다, 시점 명시) + practical + common + 용어집. 겁주기("회사 데이터 넣으면 큰일")가 아니라 "안전선을 알고 쓰면 잘리지 않는다"로. 장 제목이 "잘리지 않는"이라 독자 불안을 건드리니, 불안 증폭이 아니라 통제감을 주는 톤. 실행 도구(비식별화 체크리스트, 약관 확인 질문 목록)를 손에 쥐여줄 것.
