# 챕터 브리프: ch05 ([프로젝트 1-A] 주간 성과 보고서: 데이터 취합 자동화)

2부(실전편)의 첫 장. 1부 원리를 처음으로 실제 시스템에 적용한다. **V-1 완료로 경로 확정.**

- **독자가 얻는 것 (한 줄):** 흩어진 광고 채널(네이버·메타·구글) 데이터가 한 곳(구글 시트)에 자동으로 모이는 통로를, 코드 한 줄 없이 만든다.
- **이 챕터가 답하는 질문:** "채널 3곳 데이터를 매주 손으로 내려받아 합치는 그 1시간 40분을, 사람 손 없이 시트에 모을 수 있나?"

## 확정 경로 (스파이크 + V-1 결과)
- **기본 경로 = 플랜 A(순수 노코드):** 네이버는 **아임리포트(구글 시트 부가기능)** — 설치(클릭) → 네이버 광고 키 3종(액세스 라이선스·비밀키·고객ID) 발급·복붙 → 시트에 자동 갱신. 메타·구글은 성숙한 커넥터/공식 부가기능. (V-1: 난도 '하', VLOOKUP 수준 가능)
- **플랜 B(분기 박스):** 아임리포트가 안 맞거나 죽으면 네이버만 주 1회 보고서 수동 다운로드(약 5분) → 시트 업로드, 이후 자동. "코드 없이"·"검수 40분" 약속은 양쪽 다 유지.
- **가격:** 아임리포트 월 9,900원·14일 무료 — **발행인 실측치, 본문에 쓰되 "2026년 6월 기준" 명시 + [확인필요: 출간 직전 라이브 페이지 재확인]** (휘발성, 원 페이지 403이었음).

## 다뤄야 할 핵심 내용
1. **도입:** 김지유의 월요일 첫 1시간 40분(3채널 다운로드→취합) 장면. 1장에서 분해했던 그 시간을 여기서 처음 없앤다.
2. **원리 먼저(도구 위에 남는 것):** 왜 시트를 허브로 쓰나(비개발자가 검수·공유 가능한 유일한 공용 데이터 허브). **"취합은 단순 수집이 아니라 나만의 분류표(구조)를 만드는 일"** — 저자 실경험(`notes/author-experience.md`)의 개념 핵심. 어떤 칸으로 모을지를 정하는 게 자동화의 절반.
3. **절차(2026년 6월 기준 버전 박스):** API 키를 "은행 OTP 발급"에 비유해 단계별 — 무엇을 한다 → 무엇이 보인다 → 안 되면 어떻게 한다. 네이버(아임리포트)·메타·구글 각각. UI 버튼 위치 의존 최소화(동작 개념 중심).
4. **채널별 난도 차이 정직하게:** 네이버 키 발급(도구>API 사용 관리)이 유일한 진입 장벽 — 여기만 또박또박. 메타·구글은 상대적으로 쉬움.
5. **실패 케이스:** 키 오입력, 권한 부족, 데이터가 안 들어올 때. (10장 장애 대응과 구분: 여기선 최초 연결 단계 실패)
6. **실행 과제:** 독자가 자기 채널 1곳을 실제로 시트에 연결해보기.

- **다루지 않는 것:** 모인 데이터의 분석·보고서·슬라이드 생성(6장), 모니터링(7장), 일상 장애 대응(10장), 보안(11장 — 단 광고 데이터에 고객정보 섞이면 "11장에서 다룬다" 한 줄 포인터). 1~4장 원리 재설명 금지(참조만 — 명세는 3장, 검증은 4장).
- **자료카드:** `research/ch05-spike.md`(이미 존재 — 카드 1~15 + V-1 결과) 활용. 부족분만 `research/ch05-build.md`로 보강(메타 Make Facebook Insights·구글 공식 시트 부가기능의 2026년 6월 연결 절차 원리, 아임리포트 설치 흐름). 저자 경험은 `notes/author-experience.md`.
- **예상 분량:** 13,000자 (±20%) — 2부 절차 장이라 김.
- **앞뒤 연결:** 1장(보조→자동화)·3장(명세)·4장(검수) 받음. 6장에 "한 시트에 모인 데이터"를 넘김. 12장(아임리포트 = 서드파티 존속 리스크) 연결 한 줄.
- **스타일 유의:** ai-howto(버전·시점 명시 의무, 재현성, 원리/절차 분리) + practical(실패 케이스·실행 과제 필수) + common + 용어집. **페르소나 가드레일: 코드 한 줄 없이. API "호출"·구분자 파싱·자체 도구 제작 같은 개발 영역은 기본 경로에 넣지 마라**(저자 경험의 기술 방식은 보존하되 본문 기본 경로 아님). 첫 문단 일반론 금지.
