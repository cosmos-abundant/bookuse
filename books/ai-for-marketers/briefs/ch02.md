# 챕터 브리프: ch02 (자동화할 일 고르는 법 — 반복성×규칙성 매트릭스)

- **독자가 얻는 것 (한 줄):** 자기 주간 업무 목록에서 자동화 1순위 3개를 뽑아낸다.
- **이 챕터가 답하는 질문:** "다 자동화하고 싶다. 그런데 무엇부터, 그리고 무엇은 절대 하면 안 되나?"
- **다뤄야 할 핵심 내용:**
  1. **1장 실행 과제의 회수 (에디터 인계 지침):** 1장에서 독자가 적어온 "새로 친 프롬프트 3개"(3칸 기록 양식)를 이 장의 입력으로 사용한다. 1장에서 심은 규칙성 직관을 여기서 정식 개념으로 회수. 도입은 그 목록을 꺼내는 장면에서 시작하는 것을 검토.
  2. **평가 3축: 반복 빈도 × 규칙 명확성 × 실패 비용.** 각 축의 판정 질문과 김지유 업무 예시. 축마다 "애매할 때 가르는 기준" 포함.
  3. **매트릭스 운용:** 3축을 실무에서 쓸 수 있는 2×2(+실패 비용 오버레이) 형태로. 사분면별 처방: 지금 자동화 / 명세부터 정비(3장 연결) / 보조로 충분 / 건드리지 마라.
  4. **"자동화하면 안 되는 일" 목록:** 판단·관계·책임이 걸린 일. 왜 안 되는지를 실패 사례 또는 근거와 함께 (자료카드 필수 — 일화 지어내기 금지).
  5. **실행 과제: 내 주간 업무 15개를 매트릭스에 배치하고 1순위 3개 선정.** 단계별 절차(무엇을 한다→무엇이 보인다→안 되면), 15개가 안 나올 때의 보조 질문 포함.
- **다루지 않는 것:** 명세 작성법(3장), 도구 선택·구축(5장~), 검증 체계(4장 — 실패 비용 축에서 예고만). 1장의 3단계 모델 재설명 금지(참조만).
- **자료카드:** `research/ch02-*.md` — ①업무의 자동화 적합성 판별 기준에 대한 업계·학계 근거(RPA/자동화 후보 선정 프레임워크, 1차 출처 우선) ②자동화 실패·역효과 사례(규칙 불명확한 일을 자동화했을 때, 실패 비용 큰 일의 사고 사례 — 실명·출처 있는 것만) ③"판단·관계·책임" 업무를 자동화에서 제외해야 한다는 근거(연구 또는 권위 있는 가이드라인) ④(기존 카드 활용) `research/ch01-foundations.md` 카드 09(Anthropic 워크플로/에이전트 구분)는 ch02~04용으로 예약됨 — 사용 검토.
- **예상 분량:** 8,000자 (±20%)
- **앞뒤 챕터 연결:** 1장에서 받는 것 — 3단계 모델, 실행 과제 목록(프롬프트 3개), "위임은 정거장" 개념. 3장으로 넘기는 것 — "규칙이 애매해서 매트릭스 왼쪽에 떨어진 일을 오른쪽으로 옮기는 도구가 명세"라는 연결.
- **스타일 유의:** ai-howto + practical + common + 용어집(`glossary.md` — 보조/위임/자동화 정의 준수, 교차 참조는 절 이름으로). 1부 원리 장이므로 도구 버전 의존 최소화. 도판 후보(매트릭스)가 본문 표와 중복되지 않게 작가는 표 남발 금지.
