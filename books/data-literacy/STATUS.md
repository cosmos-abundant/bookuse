## 특별 지침 (편집장 메모)

- **★ 과업 B 선행 게이트 (6장 인과·9장 기저율):** 두 장은 **통계 전공 감수의 개념 검증을 초고 착수 전 통과**해야 한다(감수 통과 전 집필 금지). 환원한 직관(6장 "다른 조건이 같아야 한다" / 9장 "기저율이 결론을 지배 + 1만 명 머릿수 그림")이 통계적으로 정확한지 fact-checker(통계 전공 모드)가 서명해야 초고 시작. "쉽게 풀되 정확"의 실패 = 책 신뢰 붕괴.
- **11장 화법 발동 규칙:** 과업 D(먹힘/역효과 실제 대비 + 통하는·안 통하는 조건)를 챕터분만큼 확보 못 하면 11장을 독립 장으로 두지 말 것 — 6,000자 이하 축소 또는 3부 흡수. 실증 없는 추상 화법 금지.
- **3·5장 (평균·증감률):** "카드뉴스에 다 있는 얘기" 이탈 방지 — 회의 의사결정 실수로 번진 실제 사례를 초반에. 5장은 양방향 판단선(멈춤/통과 둘 다). 과업 A 1순위 중 1순위.
- **과업 C (경쟁서·시장 수치):** 출간 전 fact-checker 전수 게이트.
- **용어 표기 통일 (출간준비 통합 교정):** "퍼센트포인트"가 책 표준(프로즈), "(%p)"는 장별 1회 정의, 제목은 "%p" 허용. ch04가 "%포인트"를 써 불일치 — 출간준비 통합 교정에서 ch04를 표준으로 정규화할 것.
- **과업 E (베타 리더 실습 — 발행인 실세계 과업):** 비분석 직군 3인에게 12장 실습 → "함정 3개 이상 발견" 약속 검증. 출간준비 전까지.
- 사례는 전부 "회의에서 받아 본 숫자" 맥락(소비 측), 학술 사례 도피 금지. 가상 사례 챕터당 1회 이하(practical.md).
