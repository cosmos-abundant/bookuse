## P1 해소 확인

### ★ P1-#1 (오차범위 정확성) — 해소

- **ⓐ 한국 특정 제거·일반화:** 해소. 51행이 "인구 수십만의 작은 도시든 수천만 규모의 큰 나라든"으로 바뀌어 "인구 5,000만의 나라"라는 한국 특정 신호가 사라졌다. 미확인 목록의 "한국 직접 수치 금지"와 충돌 없음.
- **ⓑ 표본오차/비표본오차 단서:** 해소. 53행이 신규 단락으로 들어가 ① "모든 사람이 똑같은 확률로 뽑히도록 무작위로 골랐을 때만" 나오는 값임, ② 95% 신뢰수준을 "100번 조사하면 95번은 진짜 값이 이 범위 안"으로 용어 노출 없이 정확히 환원, ③ "사람들이 답을 안 하거나 질문이 한쪽으로 유도하는 데서 생기는 어긋남은 들어 있지 않다 … 그런 비틀림이 끼면 진짜 값은 ±3%포인트 바깥에서 더 크게 어긋난다"로 비표본오차의 방향까지 명시. r1이 요구한 "최선의 경우의 표본오차일 뿐"이 53행 마지막 문장("운 좋게 무작위가 잘 됐어도 우연히 이만큼은 틀린다는 최선의 경우의 폭")으로 정확히 안착.
- **통계 전공자에게 깨질 단정 잔존 여부:** 없음. 51행의 "약 ±3%포인트 안에서 추정할 수 있다"가 이전엔 무조건적 보장처럼 읽혔으나, 바로 다음 53행이 "무작위일 때만 / 우연만 따진 폭 / 비표본오차 제외"로 삼중 한정해 보증 단정이 해소됐다. 55행이 "무작위성이 빠지면 오차범위 계산 자체가 의미를 잃는다"로 전제를 한 번 더 못 박아 카드 01 휘발성 단서를 본문이 지켰다.

### ★ P1-#2 (Literary Digest 위계) — 해소

- **두 편향 동등 단정 보정:** 해소. 39행이 "치우침이 두 단계로 쌓였는데, 둘의 무게가 같지는 않았다"로 위계를 선언하고, 추출 편향(명단)은 "먼저 명단부터 기울어 있었다"로 살리되, "그런데 결정타는 그다음이었다 … 답한 사람들이 또 한쪽으로 더 치우쳤다"로 무응답(자발적 응답) 편향을 결정타로 명확히 위계화했다.
- **카드02 Squire 경고와 충돌 여부:** 없음. 39행이 "이 사건을 분석한 연구는, 답하지 않은 다수까지 모두 답했더라면 적어도 승자는 맞혔을 것이라고 본다. 명단이 기운 것만으로는 승패가 뒤집히지 않았을 수도 있다는 뜻"으로 Squire 경고("모두 답했더라면 승자는 맞혔을 것" / "추출 편향만으로는 안 뒤집혔을 수 있다")를 거의 직역 수준으로 반영. 카드02 반대 근거와 정합.
- **하나의 원인으로 단정 회피:** 충족. "기운 명단 위에 답한 사람의 치우침이 더 무겁게 포개지고"로 두 원인의 결합을 유지하면서 비중만 차등화 — 추출 편향 단독 원인으로도, 무응답 단독 원인으로도 단정하지 않았다.

## P2 해소 확인

- **#3 핵심명제 과반복:** 해소. 강한 진술은 선언(9행)·결정타 착지(31행)·클라이맥스(43행)·판단선(71행) 네 곳에 보존됐고, r1이 압축을 요구한 33행·47행·59행의 중복 선언이 다른 논지로 전환됐다(33행은 "직관에 어긋나는 대목/잘못 뽑은 표본은 키울수록 위험"으로, 47·49행은 "정반대로 미끄러진 것"이라는 반대 경고로). 동일 문장 수준 반복 6회 초과 문제는 사라졌다.
- **#4 6절 통과 기준 vs 3절 멈춤 모순:** 해소. 67행이 "통과의 기준은 어디까지나 무작위성과 대표성이지 크기가 아니다 — 답하고 싶은 사람만 답한 숫자는 25만 명이어도 통과가 아니다. 머릿수가 크다는 이유로 통과시키는 칸은 없다"로 명시. r1 지적("치우친 큰 표본은 통과 아님")이 정확히 들어가 3절의 "거대한 자발적 응답은 멈춘다"와 모순 없이 맞물린다. 추가로 69행이 "절대 수준 vs 추세 방향"을 갈라(r1 #4의 봉합 문구) 저위험 정기 지표 통과를 별도 논리로 분리, 충돌을 한 번 더 닫았다.
- **#5 도입 괄호 형식 변주:** 해소. 5행 괄호가 "특정 회사 사례가 아니라, 분모를 가린 만족도가 결정을 끄는 전형을 보여 주려 구성한 장면이다. 메커니즘 자체는 뒤에서 실제 조사들로 확인한다"로 짧아져 ch03 17행과 동일 패턴 피로가 완화됐다. 뒷부분 "실제 조사로 확인" 약속은 3절(Literary Digest·백신)에서 회수됨 — 유지.
