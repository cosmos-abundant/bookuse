## 4. 보존 구간 무손상 확인 (지정 7개소 전수)

사실·논리·수치 무손상, 오탈자 없음 — 모두 미수정:

1. **±3%포인트 비표본오차 단서 문단**(53·55행): 95% 신뢰수준 풀이, "운 좋게 무작위가 잘 됐어도 우연히 이만큼은 틀린다"는 한정 그대로. 무손상.
2. **"무작위로 뽑은 1,000명" 한정+반례**(55행): 240만·25만 반례 연결 그대로. 무손상.
3. **Literary Digest 무응답 위계 문단**(37·39행): "약 240만/5만", 명단 편향 < 무응답 편향 위계, "승자는 맞혔을 것" 논지 그대로. 무손상. (단 수치 출처는 5절 감수 이관)
4. **Big Data Paradox "정밀하게 틀린 답"**(43행): "치우쳐 모은 100만 명 < 무작위 1,000명", 양이 질을 대신 못 함 그대로. 무손상.
5. **클라이맥스 수치**(37·41행): 240만→5만, 25만, 17%포인트 그대로. 무손상.
6. **9장 경계 문단**(75·77행): "물어본 사람" vs "아예 안 잡힌 사람" 경계, 9장 이관 명시 그대로. 무손상.
7. **±3%p 비표본오차 단서**(53행 후반): 무응답·유도질문 누락분은 ±폭 바깥이라는 핵심 단서 그대로. 무손상.

> 참고: 5·57·87행 수정은 모두 보존 구간 밖이거나(5·87) 보존 구간(57행은 "작아도 괜찮은 표본" 절 내) 내라도 어미 병렬만 손댄 비의미 수정으로, 사실·논리·수치에 무영향.

## 5. 감수 이관 항목 (fact-check 단계 별도)

수치·출처 진위는 교정 범위 밖. 아래는 본문이 이미 "근사/방향만 본다"는 완화 장치를 단 곳이나, 출처 검증 필요:

1. **Literary Digest(1936)**: 발송 약 1,000만, 회수 약 240만(4분의 1), 갤럽 약 5만. 본문에 "자료마다 다르므로 근사로 둔다" 단서 있음 — 자료카드 대조 요망.
2. **2021 코로나 백신 접종률 설문**: 약 25만 명/약 7만 5,000명, 약 17%포인트 과대추정, 네이처 발표·"발표 시점 추정치" 단서. 수치·게재지(Nature) 확인 요망.
3. **하버드 통계학자 / Big Data Paradox**: "정밀하게 틀린", "치우친 100만 < 무작위 1,000명" 귀속 인물·표현 출처 확인(본문은 익명 처리 "하버드의 한 통계학자").
4. **온라인 상품평 J자/양극 분포 실험**(29행): "구매자 전원에게 리뷰를 쓰게 한 실험에서 좌우 대칭" 주장의 출처 확인.
5. **전국 여론조사 1,000명 ≈ ±3%포인트, 인구 크기 무관**(51행): 표준 통계 사실이나 자료카드 근거 유무 확인 권장.
