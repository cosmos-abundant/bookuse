### 문장 다듬기·리듬 (7건)
- 3번: "110억 달러짜리 결정이었다. 한 번 회사를 통째로 사들이면 되돌릴 수 없는 결정이기도 했다." → 두 문장을 "~결정이었고, ~결정이기도 했다"로 연결 (단문 나열 완화. 수치·내용 무손상)
- 13번: "30분, 40분이 간다" → "흐른다" (구어적 '가다' 정돈)
- 25번: "또 그래야 한다고 그는 적었다" → "또 그래야 한다는 것이었다" ("그는 적었다" 2연속 동일 문형 변주. 베이조스 2015 주주서한 ★보존, 내용 무손상)
- 29번: "통과 쪽, 크면 멈춤 쪽으로 기울인다" → "통과 쪽으로, 크면 멈춤 쪽으로 기운다" (타동사 '기울이다'의 자동사 오용 교정 + 조사 병렬 정돈)
- 47번: "쓰려면 두 줄이면 된다" → "쓰는 데는 두 줄이면 된다" (조건어미 '-려면 ~면' 중복 해소)

- 69번: "작은 데서 트집을 잡다, 정작" → "잡다가, 정작" (연결어미 '-다'로 두 절을 잇는 비문 → '-다가')

### 어휘 중복 제거 (2건)

### 표기 일관성 (1건)

## 3. 의사결정 학술어 일상어 환원 — 유지 확인 (수정 불요)
ch10 본문은 학술어를 노출하지 않고 일상어로 환원돼 있어 환원 작업은 "확인"으로 종료.

- one-way door / two-way door → "되돌릴 수 있는 문 / 되돌릴 수 없는 문"(절제목·도입·그림·본문). 27번 1곳을 대칭 표기로 통일(위 §1).
- prospect theory(손실 회피) → "작은 데서 한 번 틀려도 별일 아니다 / 큰 데서 틀리면 회복이 안 된다", "틀렸을 때 잃는 게 크기 때문"(35번). 학술어 노출 0.
- value of information → "결정을 바꾸지 못하는 검증은 값어치가 0이다"(49번), "더 따질수록 더 확실해지는 것도 아니다 / 정보를 한 조각 더 모을 때마다 ~ 흔들리기도 한다"(15번). 작업 지시의 "결정을 안 바꾸는 검증은 값어치 없다" 환원 살아 있음.
- analysis paralysis → 용어 미사용. "어떤 결정도 못 내리고 끝난다"(15번), "완벽한 답을 기다리며 결정을 미루는 사이"(15번)로만 서술. 작업 지시 "결정이 멈춘다" 취지의 일상어 환원 유지. (ch08·ch09는 "분석 마비"를 직접 쓰나 ch10은 풀어 씀 — 노출 0건이므로 문제 없음, 아래 제안 2 참조)
- "검문 자본"(77번)·"한정된 자본"(17번): 학술어 아닌 본문 비유어로 일관.

## 6. 편집장 판단 필요 (제안 — 직접 수정 안 함)

1. **"여섯 장" vs ch09 "여덟 개 함정 장" (63번)**
   ch10 63번 "2부가 여섯 장에 걸쳐 다른 함정을 다뤘지만" / 81·95번류 → 본문이 직접 인용한 장(3·4·5·7·8·9)이 정확히 여섯이라 ch10 내부는 정합. 그러나 ch09 마지막은 "2부의 여덟 개 함정 장이 끝난다"로 2부 전체를 여덟으로 셈. 독자가 두 숫자를 비교하면 혼란 가능. 구조/사실 영역이라 직접 손대지 않음. → 편집장이 "본문 언급 장 수(여섯)"임을 받아들일지, 한 줄 단서를 넣을지 판단. (fact/구조 이관 성격 약함, 표기 정합 이슈)

2. **"분석 마비" 용어 비노출 일관성**
   ch08·ch09는 결말에서 "분석 마비"(glossary 등재)를 명시. ch10은 같은 개념을 풀어만 씀(노출 0). 시리즈 일관성상 ch10에도 "분석 마비"를 한 번 못 박을지, 아니면 ch10의 일상어 서술을 그대로 둘지 편집장 결정. (현 상태로도 규범 위반 아님 — 보존 권장)

3. **만족도 점수 발화 표기 ("4.2" vs "4.2점")**
   71번 회의 발화 "이 식당 평점 4.2 맞아요? 4.0 아니에요?"는 '점' 생략(입말), 35·49번 서술은 "4.2점"·"4.1/4.3"으로 '점' 부착·소수점 일관. 입말/글말 구분으로 보존했으나, 발화에도 '점'을 붙여 통일할지 여부는 톤 판단 영역. (현행 유지 권장)
