### 문법(비문) 복구 — 1건
- **69행.** "상관을 인과로 단정하는 **데** 익숙하게 의심하다 보면" → "상관을 인과로 단정하는 **걸** 익숙하게 의심하다 보면"

  - 위치 확인: 69행은 C9 균형추 본문(71행, ★보존)으로 들어가는 도입부로, **C-보존 목록에 속하지 않는 문장**임을 확인하고 손댐. 71행 자체는 미손상.

### 그 외 유형 — 직접 수정 0건
- 맞춤법/띄어쓰기: 검출 0(되/돼, 률/율, 안+용언 띄어쓰기, 의존명사 '리/것/만' 띄어쓰기, 보조용언 띄어쓰기 모두 정상).
- 번역투/군더더기: 금지 목록("~에 있어"·"~함에도 불구하고"·"~에 다름 아니다"·"~라고 할 수 있다"·이중피동·"가지다" 남용) 전수 검사 결과 검출 0.
- "들" 남용: 검출된 인스턴스(사람들·실험들·마케터들·설명들·증거들)는 모두 필요 복수. 9행 등은 ★보존 문장. 수정 없음.
- 문장부호: 줄표(—) 앞뒤 한 칸 띄움 일관(glossary 규칙 부합). 절제목 콜론(15·43·75·95행)은 부제 컨벤션으로 일관 — 유지.

## 4. 통계 용어 환원 항목 (대전제 부합 확인)

ch06 본문 서술에 노출돼선 안 되는 통계 용어를 전수 점검한 결과 **환원할 잔존 용어 0건** — writer가 집필 단계에서 전부 일상어로 환원해 둠:

| 통계 용어 | 본문 환원 표현 | 상태 |
|---|---|---|
| 교란변수(confounder) | "둘 다 끌어올린 숨은 제3의 것" | 노출 0 ✓ |
| 반사실(counterfactual) | "반대 장면 / 안 했다면 어땠을까" | 노출 0 ✓ |
| 역인과(reverse causation) | "방향이 거꾸로" | 노출 0 ✓ |
| 가짜 상관(spurious) | "우연히 닮은꼴 / 우연의 닮은꼴" | 노출 0 ✓ |
| RCT | "무작위로 나눠 본 비교"(43행 절제목·본문) | 노출 0 ✓ |
| 교환가능성(exchangeability) | "평균적으로 닮은꼴"(49·51행) | 노출 0 ✓ |

## 6. 감수 이관 항목 (fact-check 별도 — copy-edit에서 손대지 않음)

1. **흡연-폐암 배수(79행, [확인필요-1]).** 본문은 게이트 정정안대로 "수십 배" 정성 표현으로 안전하게 처리돼 있음. 정밀 배수 확정(British Doctors Study 컷·연도)은 출간준비 fact-checker 몫. copy-edit 무개입.

3. **로널드 피셔·대럴 허프 정황(77·83행).** "담배업계를 위해 동원" 서술은 과거형·정황 표현. 피셔 개인 동기 단정은 본문에 없음(게이트 미확인 목록 부합). fact-check 시 허프-담배업계 연결의 1차 출처만 재확인 권고.
