# 도판 스타일 규칙 — 데이터 문해력 실용서(가제: 끄덕이는 사람과 되묻는 사람)

- 적용 범위: 이 책의 모든 도판(다이어그램·플로차트·차트·표·일러스트 브리프).
- 기본 방침: **장식이 아니라 이해를 위한 도판.** 글로 충분한 곳에 그림을 넣지 않는다. 이 책 독자(페르소나 "박서연" = 통계 약한 8년 차 비분석 직군)는 통계 기호·수식·왜곡 차트에 거부감이 크다. 따라서 이 책의 도판은 **개념 다이어그램·판별 플로차트·비교 표 위주**로 간다. 통계 기호(σ, p값 등), 수식, 축 절단 그래프는 이 책 도판에 쓰지 않는다(본문이 비판하는 대상이므로 도판에서 흉내조차 내지 않는다).
- 관리: illustrator가 유지. 규칙 변경 시 기존 도판 소급 갱신 여부를 함께 기록.
- 1권(『마케터의 월요일을 돌려드립니다』) 스타일을 뼈대로 계승하되 강조색·강조 의미만 이 책 톤(검문)에 맞게 재정의한다. 두 책이 한 출판사 시리즈로 보이도록 잉크색·폰트·캡션 형식은 동일하게 유지한다.

## 1. 색

단색 잉크 + 강조색 1개 원칙. 도판 하나에 색은 최대 4개(잉크·강조·보조회색·배경).

| 역할 | 색 | 용도 |
|---|---|---|
| 잉크 | `#243B53` | 선, 본문 텍스트, 기본 테두리 |
| 강조 | `#2B6CB0` | **단 하나의 핵심**(검문관의 자세, 되묻기, 이 책이 만드는 것)에만. 도판당 1회 사용 원칙 |
| 강조 배경 | `#EBF4FB` | 강조 노드의 면 |
| 보조 회색 | `#829AB1` | 부가 설명, 축, 출처 표기, 같은 자리에 묶이는 두 자세(믿음/무시) |
| 중립 배경 | `#F0F4F8` | 일반 노드의 면 |
| 바탕 | `#FFFFFF` | 도판 배경 (투명 금지 — 전자책 다크모드 대비) |

의미 규칙: 강조색(`#2B6CB0`, 차분한 파랑)은 이 책 전체에서 **"검문관의 자세 = 받아 들고 한 줄 되묻기 = 이 책이 독자에게 만들어 주려는 상태"**를 가리킨다. 다른 의미로 쓰지 않는다.
- 1권은 강조색이 주황(`#D9480F`, 자동화/목표)이었다. 이 책은 파랑으로 바꿔 시리즈 안에서 책별 정체성을 준다(주황=실행 가속, 파랑=검문·판단). 두 색을 한 도판에 섞지 않는다.
- "믿음"과 "무시"처럼 본문이 *같은 자리에 묶는* 두 잘못된 자세는 강조색을 주지 않고 보조 회색 계열로 둔다(시각적으로도 "한편"임을 드러낸다).

## 2. 선·도형

- 선 굵기 1.5px, 강조 박스 테두리 2px. 점선(`4 3`)은 "아직 아닌 것/주석/가상/페르소나 서사"에만.
- 모서리 둥글기 4px. 화살표는 단순 삼각형, 곡선 대신 직선·직각(mermaid `curve: linear`).
- 그림자·그라데이션·3D 금지.

## 3. 폰트

- 한글: Pretendard → 'Noto Sans KR' → sans-serif 폴백.
- 도판 내 텍스트 크기: 제목 15px(bold), 본문 13px, 주석·출처 11px. 도판 안에서 3단계를 넘기지 않는다.
- 숫자·기호 강조는 크기와 강조색으로만. 이탤릭 금지(한글 가독성). **통계 기호·수식은 도판에 넣지 않는다**(이 책 톤 원칙).

## 4. 캡션·번호·대체 텍스트 (모든 도판 의무)

- 번호: `그림 N-M` (챕터-순번). 표는 `표 N-M`.
- 캡션 형식: `그림 N-M. 한 문장 설명(마침표로 끝남).` 데이터 도판은 둘째 줄에 출처를 붙인다: `출처: 기관, 「보고서명」, 조사 시점.` 서로 다른 조사의 수치를 한 도판에 쓰면 **각 수치에 시점을 분리 표기**한다.
- **무결성(이 책 특칙):** 페르소나 박서연의 서사 수치(전환율 12%, 만족도 4.6점 등)는 가상 사례다. 도판에 등장시킬 경우 노드/캡션에 "가상 사례"임을 반드시 명시하고 점선 처리한다. 자료카드에 없는 수치는 도판에 만들지 않는다. 본문 수치와 도판 수치가 다르면 작업 중단·편집장 보고.
- 대체 텍스트: 도판이 전달하는 판단/구조를 문장으로. "～를 나타낸 다이어그램" 같은 형식 묘사 금지. 수치 도판은 수치를 본문 그대로 포함(가상 수치는 "가상"이라 함께 명시).
- 파일 내 기록 위치: `.mmd`는 머리의 `%%` 주석, `.svg`는 머리의 XML 주석 + `<title>`/`<desc>`, `.brief.md`는 전용 섹션.

## 5. mermaid 표준 헤더

모든 `.mmd` 파일은 아래 frontmatter로 시작한다.

```yaml
---
config:
  theme: base
  themeVariables:
    fontFamily: "Pretendard, 'Noto Sans KR', sans-serif"
    fontSize: "13px"
    primaryColor: "#F0F4F8"
    primaryTextColor: "#243B53"
    primaryBorderColor: "#243B53"
    lineColor: "#243B53"
    secondaryColor: "#FFFFFF"
    tertiaryColor: "#EBF4FB"
  flowchart:
    curve: linear
---
```

공통 classDef (필요한 것만 선언해 사용):

```
classDef accent fill:#EBF4FB,stroke:#2B6CB0,stroke-width:2px,color:#243B53;
classDef neutral fill:#F0F4F8,stroke:#243B53,color:#243B53;
classDef muted fill:#FFFFFF,stroke:#829AB1,color:#829AB1;
classDef note fill:#FFFFFF,stroke:#829AB1,stroke-dasharray:4 3,color:#829AB1;
```

- `accent` = 검문관의 자세(강조, 도판당 1회).
- `neutral` = 일반 단계·항목.
- `muted` = 본문이 "한편으로 묶는" 잘못된 자세(믿음/무시) 등 깎아내릴 대상. 회색 실선.
- `note` = 주석·가상 사례·페르소나 서사. 회색 점선.

## 6. 데이터 도판(차트) 규칙

- 이 책 ch01은 개념 장이라 차트를 쓰지 않는다(페르소나 배려). 후속 장에서 차트가 필요하면:
- 수치는 `research/` 자료카드에 있는 것만. 임의 생성·보간·반올림 변경 금지. 본문 수치와 다르면 작업 중단·편집장 보고.
- 가상 사례(박서연 서사 수치)는 실측과 시각적으로 구분(점선/회색)하고 캡션에 "가상"이라 명시한다.
- 축 생략·절단으로 차이를 과장하지 않는다. %는 0~100 기준. (이 책이 본문에서 비판하는 함정을 도판이 저지르지 않는다.)

## 7. 표 규칙

- 마크다운 표. 헤더 1행, 비교 항목 3개 이상일 때만 표로. 셀 안 문장은 2줄 이내.

## 8. 일러스트 브리프 (외부 생성용)

- 이 책은 실용서이므로 분위기용 일러스트는 원칙적으로 쓰지 않는다. 쓴다면 챕터 표제지/부 표제지 한정, 플랫 2색(잉크 `#243B53` + 강조 `#2B6CB0`) 라인 일러스트, 사람 얼굴 디테일 금지(박서연은 가상 합성 인물 — 특정 인물화 방지), 실제 차트·통계 기호·기업 로고 묘사 금지.
- 브리프 필수 항목: 장면, 구도, 스타일 지시(위 색·선 규칙 참조), 금지 요소, 영문 프롬프트 초안, 삽입 위치·캡션·대체 텍스트.
